# Study execution evidence

This supplementary bundle preserves the completed four-job supervisor, launch logs and receipts, frozen plan and source identities, and all 695 load samples. The timing reports and runtime archives remain separate. See [inventory.json](inventory.json) for file hashes and sampling limits, and [study-execution.tar.gz](study-execution.tar.gz) for the original evidence.

No sample flagged other compute activity above 5% on the selected GPU. Sampling every 30 seconds cannot establish exclusive hardware use or rule out activity between samples. The study used a shared workstation. Raw timings and failure exclusions are unchanged.
